Em linguagem simples

Claude Code

Um assistente de IA que trabalha no seu computador. Lê e cria ficheiros, abre o navegador e liga-se às suas ferramentas. Você fala com ele por escrito, em português.

Agente

Um "funcionário digital" com uma função só: tratar dos anúncios, responder a leads, controlar faturas. Cada um sabe as regras da sua empresa.

Skill

O manual de instruções de um agente. É um ficheiro de texto com o passo a passo de uma tarefa. Escreve-se uma vez e o agente segue-o sempre.

MCP (conector)

A "ficha" que liga o Claude Code a outra plataforma, como o Meta Ads ou o Google Ads, para ele trabalhar lá dentro com a sua autorização.

VPS

Um computador alugado na internet que fica ligado 24 horas. Serve para os agentes que precisam de trabalhar mesmo com o seu computador desligado.

Orquestrador

O gerente da equipa. Aqui chama-se Hermes: recebe o seu pedido, divide-o pelos agentes certos e mostra-lhe o resultado.

Passo 3

Instalar o Claude Code

Há duas formas. Se nunca abriu um terminal, use a aplicação de computador. Se já está à vontade, o terminal dá mais controlo.

  1. Crie conta e escolha o plano em claude.ai (passo 2).

  2. Descarregue a aplicação Claude em claude.com/download e instale como qualquer programa.

  3. Entre com a sua conta e abra a área Code da aplicação.

  4. Escolha uma pasta para a empresa, por exemplo Documentos/Empresa-IA. É aí que os agentes vão viver.

  5. Teste: escreva "Olá, explica-me em 3 linhas o que consegues fazer nesta pasta." Se responder, está pronto.

  1. Abra o Terminal: carregue em Cmd + Espaço, escreva "Terminal" e Enter.

  2. Cole este comando e carregue em Enter. Não mostra progresso; espere até voltar a aparecer o cursor.

    curl -fsSL https://claude.ai/install.sh | bash

  3. Feche e abra outra vez o Terminal e confirme que ficou instalado:

    claude --version

  4. Crie a pasta da empresa e entre nela:

    mkdir -p ~/Empresa-IA && cd ~/Empresa-IA && claude

  5. Faça login: abre-se o navegador; entre com a conta do plano pago.

  1. Abra o PowerShell: botão Iniciar, escreva "PowerShell" e Enter. Não precisa de ser administrador.

  2. Cole este comando e carregue em Enter:

    irm https://claude.ai/install.ps1 | iex

  3. Recomendado: instale o Git for Windows (opções por defeito).

  4. Feche e abra outra vez o PowerShell e confirme:

    claude --version

  5. Crie a pasta da empresa e entre nela:

    mkdir $HOME\Empresa-IA; cd $HOME\Empresa-IA; claude

  6. Faça login no navegador que se abre, com a conta do plano pago.

Se algo falhar

Escreva no terminal claude doctor. Mostra o que está mal e como corrigir. Requisitos: macOS 13 ou mais recente, Windows 10 (1809) ou mais recente, 4 GB de RAM.

Fonte: documentação oficial do Claude Code.

Passo 4

Ligar o Claude Code ao Chrome

Com a extensão, o Claude Code mexe no navegador por si: abre o Gestor de Anúncios, preenche formulários, tira dados de sites. Trabalha num separador visível, por isso vê tudo o que ele faz.

  1. Instale a extensão "Claude" na Chrome Web Store e entre com a mesma conta.

  2. Abra o Claude Code com o navegador ligado:

    claude --chrome

  3. Na primeira vez aparece uma janela a explicar as permissões. Carregue em Enter.

  4. Para ficar sempre ligado: dentro do Claude Code escreva /chrome e escolha "Enabled by default".

  5. Teste: "Abre o site da minha empresa e diz-me se há algum erro na página inicial."

Segurança no navegador

Crie um perfil do Chrome só para o trabalho com IA, sem banco, finanças ou dados de saúde. O Claude pára nos logins e CAPTCHAs e pede-lhe para os fazer. Nunca lhe dê palavras-passe nem dados de cartão.

Fonte: Claude Code com Chrome.

Passo 7

Servidor, site e conectores

VPS: o computador sempre ligado

  1. Compre uma VPS com Ubuntu 24.04. Referência: Hostinger KVM 2 (2 vCPU, 8 GB RAM, 100 GB). Escolha um centro de dados na Europa.

  2. Não precisa de configurar à mão. Depois de colar o prompt final, o Claude Code guia-o: cria um utilizador sem privilégios, ativa a firewall, bloqueia tentativas de entrada e instala o Claude Code no servidor.

  3. Guarde os dados de acesso num gestor de palavras-passe (Bitwarden, 1Password). Nunca os cole numa conversa.

Site: domínio e alojamento

  1. Compre o domínio .pt e o alojamento na Amen.pt, ou use a VPS para alojar o site.

  2. O agente Web cria o site a partir das suas respostas e prepara-o para publicar. Você só aprova o resultado.

Conector do Meta Ads

  1. Precisa de: uma conta no Meta Business (Gestor de Negócios) com a conta de anúncios e a Página, e ser administrador.

  2. Adicione o conector oficial da Meta ao Claude Code:

    claude mcp add --transport http meta-ads https://mcp.facebook.com/ads

  3. Autorize: dentro do Claude Code escreva /mcp, escolha "meta-ads" e faça login no Facebook. Escolha as contas e o nível de acesso. Comece por só leitura; passe a leitura e escrita quando confiar no fluxo.

  4. Regra de ouro: tudo o que o agente cria fica em pausa. É você que ativa a campanha.

Ainda em beta

O conector oficial está a ser disponibilizado aos poucos, conta a conta. Se aparecer "This ad account is not enabled for the Ads MCP", a alternativa oficial é a ferramenta de linha de comandos da Meta (pip install meta-ads-cli e depois meta auth login), que o Claude Code também sabe usar.

Conector do Google Ads

  1. O conector oficial da Google só lê dados (relatórios, desempenho). Criar campanhas faz-se pelo navegador com a extensão do passo 4, ou pela API com acesso de escrita.

  2. Precisa de: um "developer token" (Centro de API numa conta de gestor), um projeto no Google Cloud com a Google Ads API ativa, e credenciais OAuth de aplicação de computador.

  3. Depois de ter esses dados, o comando é este (substitua os valores):

    claude mcp add google-ads \
  --env GOOGLE_APPLICATION_CREDENTIALS=/caminho/credenciais.json \
  --env GOOGLE_PROJECT_ID=o-seu-projeto \
  --env GOOGLE_ADS_DEVELOPER_TOKEN=o-seu-token \
  -- pipx run --spec git+https://github.com/googleads/google-ads-mcp.git google-ads-mcp

  4. Não se assuste: o prompt final pede ao Claude Code para o guiar nisto clique a clique, com o navegador.

Fontes: googleads/google-ads-mcp, guia do conector Meta Ads.
